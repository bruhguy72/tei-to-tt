# tei-to-tt
A tool that converts TEI-XML texts into TreeTagger format for further integration into ANNIS via Annatto. It is mainly used for the [SCAT](https://scat.spb.ru/info/) project.

Usage: run xml_to_tt.py and write paths to the corpus directory, the "metadata.csv" file, and the output directory.

The project is very WIP
